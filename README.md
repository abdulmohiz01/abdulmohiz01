## What I Do

**Frontend & Motion** — I design and build performant, animated web experiences. GSAP, Lenis, smooth scroll, parallax, split-text reveals, page transitions — the kind of work you see on Awwwards. I've built 30+ production websites with these patterns, and distilled all of it into **[wespark-frontend](https://github.com/abdulmohiz01/wespark-frontend)**, my open source React component library.

**AI & Automation** — I build AI chatbots, automation pipelines, and intelligent tools. From portfolio chatbots to web scrapers to workflow automation — I connect AI to real-world problems.

**Full Stack** — When the project needs it, I go deep. REST APIs, GraphQL, PostgreSQL, Shopify Liquid, C#/.NET — whatever the stack requires.
